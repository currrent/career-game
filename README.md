# Карьера — idle-игра про удалённую работу

## Запуск локально
Откройте `index.html` в браузере. Для корректной работы сохранений и некоторых браузерных ограничений удобнее запустить простой сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages
1. Загрузите содержимое папки `career-game` в корень репозитория.
2. В настройках репозитория откройте **Settings → Pages**.
3. Выберите публикацию из ветки `main`, папка `/ (root)`.
4. После публикации игра будет доступна по адресу GitHub Pages.

## Что уже работает
- Ручной заработок по нажатию на ноутбук или большую кнопку.
- Пассивный доход каждую секунду.
- 10 карьерных улучшений с растущей стоимостью.
- 10 карьерных ступеней и шкала прогресса.
- Сохранение прогресса в localStorage.
- Начисление офлайн-дохода (максимум 8 часов).
- Ежедневный бонус раз в 24 часа.
- Достижения и статистика.
- Анимация монет, всплывающих сумм, кнопок и рабочего места.
- Адаптивная вертикальная мобильная вёрстка.

## Важные замечания перед запуском в MAX
Это автономная HTML5-игра, подготовленная под мобильный WebView и вертикальный экран. Для полноценной публикации именно как MAX Mini App нужно подключить актуальный официальный SDK MAX и обработчики авторизации/пользовательского ID согласно документации платформы. Сейчас прогресс хранится локально в браузере конкретного устройства и не синхронизируется между устройствами. Для честной экономики и защиты от накрутки потребуется серверная проверка начислений и покупок.
