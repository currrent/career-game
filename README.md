# Карьера — idle game для MAX Mini App

Мобильный адаптивный MVP. Открой index.html или запусти `python -m http.server 8000`.

## Экономика
- Старт: 0 ₽, 1 ₽ за клик.
- Каждая покупка «Стажёр» добавляет +1 ₽ к силе клика.
- Повторная цена растёт по экспоненте: ×1,42 за каждую покупку конкретного улучшения.
- 10 карьерных ступеней, пассивный доход, ежедневный бонус и офлайн-доход до 8 часов.
- Прогресс сохраняется в localStorage.

## MAX
Это автономная web-версия. Для полноценного Mini App нужно подключить актуальный MAX Mini Apps SDK; для синхронизации между устройствами — серверное хранение прогресса.

`images/concept-ui.png` — визуальный концепт. Главная сцена MVP построена CSS-слоями, чтобы позже независимо заменить ноутбук, кофе, кота и декор отдельными прозрачными PNG/WebP.
